# Учебные GUI-приложения на Python

Репозиторий содержит три учебных приложения на Python,
разработанных с использованием CustomTkinter.

Проекты демонстрируют создание графических интерфейсов,
обработку данных и их визуализацию. Mini FastQC также
поддерживает работу через командную строку (CLI).

Приложения протестированы на macOS и Ubuntu Linux.


## Задания

### 1. Калькулятор

Графический калькулятор, реализованный на Python.


### 2. Учёт пациентов

Приложение для хранения и анализа вымышленных данных пациентов.

**Возможности:**
- Добавление и редактирование пациентов.
- Удаление одной или нескольких записей.
- Автоматический расчёт индекса массы тела (ИМТ).
- Сохранение и загрузка данных в формате JSON.
- Отображение общего количества пациентов.
- Таблица с вертикальной полосой прокрутки.
- Статистическая панель с четырьмя графиками:
  - распределение по полу;
  - распределение по возрасту;
  - ИМТ по полу;
  - зависимость ИМТ от возраста.



### 3. Mini FastQC

Приложение для анализа качества данных секвенирования
в формате FASTQ с графическим (GUI) и консольным (CLI)
интерфейсами.

**Возможности:**
- Чтение и анализ FASTQ-файлов.
- Подсчёт количества прочтений и их средней длины.
- Визуализация четырёх статистических показателей:
  - среднее качество по позициям прочтения;
  - нуклеотидный состав по позициям;
  - распределение длин прочтений;
  - распределение среднего качества прочтений.
- Автоматическое масштабирование графиков при изменении
  размеров окна.
- Повторный выбор и анализ файлов без перезапуска программы.
- Выполнение анализа в отдельном потоке без блокировки GUI.
- Обработка ошибок чтения и некорректных данных FASTQ.


## Установка и запуск

Для запуска необходим Python с поддержкой Tkinter.

### 1. Клонирование репозитория
```bash
git clone https://github.com/nnvrmind/gui
cd gui
```

### 2. Создание виртуального окружения

#### Вариант 1. Стандартное окружение Python (venv)

Создание окружения в корневой папке репозитория:

```bash
python3 -m venv .venv
```

Активация на macOS / Linux:

```bash
source .venv/bin/activate
```

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

Завершение работы с окружением:

```bash
deactivate
```

Удаление окружения на macOS / Linux:

```bash
rm -rf .venv
```


#### Вариант 2. Окружение Conda

Создание окружения:

```bash
conda create -n gui python=3.12
```

Активация окружения:

```bash
conda activate gui
```

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

Если используемая сборка Python не содержит Tkinter, его потребуется установить отдельно. Для Conda можно воспользоваться:

```bash
conda install tk
```

Проверить работу Tkinter:

```bash
python -m tkinter
```

Завершение работы с окружением:

```bash
conda deactivate
```

Удаление окружения:

```bash
conda env remove -n gui
```

### 2.1 Особенности запуска на Linux

На некоторых конфигурациях Linux элементы `CustomTkinter` могут отображаться некорректно: появляются графические артефакты, пикселизация и проблемы со скруглением кнопок.

Такая проблема наблюдалась на Ubuntu 25.10 (ARM64) при использовании Tk из стандартного канала Anaconda.

#### 1. Установка Tk с поддержкой Xft

Рекомендуется использовать сборку Tk с поддержкой Xft из `conda-forge`.

Для создания отдельного окружения:

```bash
conda create -n gui -c conda-forge python=3.12 "tk=8.6.*=xft_*"
conda activate gui
python -m pip install -r requirements.txt
```

Если окружение `gui` уже существует, не нужно создавать его повторно. Перед заменой Tk проверьте предполагаемые изменения:

```bash
conda install -n gui -c conda-forge "tk=8.6.*=xft_*" --dry-run
```

**Внимание:** установка другой сборки Tk может потребовать изменения версии Python и других зависимостей.

#### 2. Проверенная конфигурация

- Ubuntu 25.10 (ARM64)
- Python 3.12
- Tk 8.6.13 с Xft
- CustomTkinter 6.0.0

Указанная конфигурация успешно использовалась для исправления графических артефактов и отображения скруглённых кнопок.

#### 3. Особенности графического интерфейса

На Linux для корректного отображения скруглённых элементов
CustomTkinter используется метод отрисовки `circle_shapes`.

Настройка применяется автоматически при запуске приложений
и не изменяет отображение интерфейса на macOS.

В некоторых конфигурациях Linux также может потребоваться
использование сеанса Xorg вместо Wayland.

Изменение системного масштаба экрана для работы приложений
не требуется.


### 4. Генерация данных пациентов

Для первоначального заполнения таблицы создайте набор из 500 вымышленных пациентов:

```python 
python patient_records/generate_data.py
```

Генератор создаст `patient_records/patients.json`.

Если файл уже существует, программа запросит подтверждение перед перезаписью.

### 5. Запуск приложений

#### Калькулятор:

```python 
python calculator/main.py
```

#### Учёт пациентов:

```python 
python patient_records/main.py
```


#### Mini FastQC

Графический интерфейс:

```bash
python -m mini_fastqc.main --gui
```

После запуска выберите FASTQ-файл с помощью кнопки
«Выбрать FASTQ». Результаты анализа и четыре статистических
графика появятся в главном окне.

Консольный интерфейс:

```bash
python -m mini_fastqc.main mini_fastqc/data/SRR41209328_1.fastq
```

Вместо указанного файла можно передать путь к любому
поддерживаемому FASTQ-файлу.

Все команды запуска выполняются из корневой папки
репозитория `gui`.


## Конфиденциальность

В приложении для учёта пациентов используются синтетические
данные, созданные с помощью Faker.

Файл `patient_records/patients.json` исключён из Git
через `.gitignore`.

Приложение является учебным и не предназначено для
хранения реальных медицинских и персональных данных.

Mini FastQC обрабатывает выбранные FASTQ-файлы локально.
Перед добавлением данных секвенирования в публичный
репозиторий необходимо убедиться, что их распространение
разрешено.
